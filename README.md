# LLMS

llms are deep neural network models that have been developed over the past few years.
They ushered in a new era for natural language processing (NLP)

An *LLM* is a neural network designed to understand, generate, and respond to human-
like text

An LLM SDK (Large Language Model Software Development Kit) is a library that lets our code talk to an LLM without manually dealing with HTTP requests, authentication, JSON formatting, retries, and response parsing
